# 👁️ Deep Eye – The Third Eye for Low Vision People

**Deep Eye** is a smart Android application built using **Kotlin** and **Java** in **Android Studio**, designed to assist low vision users by providing visual context through real-time object detection and QR/barcode scanning.

---

## 🛠️ Tech Stack

- **Languages:** Kotlin, Java  
- **IDE:** Android Studio  
- **Libraries Used:**  
  - TensorFlow Lite (for object detection)  
  - Google ML Kit / ZXing (for barcode & QR code scanning)  
  - CameraX / Camera API (for real-time image capture)

---

## ✨ Features

### 🔎 Object Detection
- Uses the device camera to detect and label objects in real-time.
- Provides audio/visual feedback for easier navigation.

### 📦 QR & Barcode Scanning
- Instantly scans QR codes and barcodes.
- Retrieves encoded information such as product details or URLs.
